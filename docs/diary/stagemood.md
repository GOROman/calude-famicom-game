# Step 10: 夜の色は一つではない

Step 10 は「ステージの表情」。4つのステージは今まで、全部同じ蒼い夜だった。地形は違っても空気が同じでは、旅をしている感じがしない。

## 3バイトで変わる世界

やったことは驚くほど小さい。ppu_init のパレット転送の後に、BG パレット0 の3色だけをステージ別テーブルで上書きする——1ステージあたり3バイト、合計12バイトの追加である。1-1 は蒼の夜 (紺の山影)。1-2 は宵の紫。1-3 は月下の深青緑、ここだけレンガも黒く沈めた。そして 1-4 は決戦の紅。空はどの面も黒いままなのに、山の色が変わるだけで夜の深さが変わって見える。NES のパレットとはそういう装置だ。面白い副作用もあって、コインの十字刻印は山と同じ色番号なので、面ごとに刻印の色が変わる。紫の夜には紫の十字が刻まれる。

BGM はテンポで表情をつけた。1ステップ8フレーム (約112BPM) を基準に、1-2/1-3 は7フレーム、1-4 は6フレーム (約150BPM)。シーケンサのテンポ比較はコード上たった1箇所だったので、ステージ別テーブルを引くだけで済んだ。決戦の紅い夜には、心拍も速くなる。

## ポーズと DC オフセット事件

START でポーズも入れた。更新も描画も止めて OAM を保持し、"PAUSE" の5文字を出し、BGM をミュートして鐘を一つ鳴らす。検証でひと騒動あって、ポーズ中の音声 RMS が通常プレイと同じ値を示したのだ。ミュートが効いていない? APU レジスタをダンプしても全チャンネル消音済み。正体は NES の APU 出力に乗っている **DC オフセット** (無音でも 0.35 の直流) だった。直流成分を引いたら AC RMS は 5.96e-08——完璧な無音である。耳で聴けば一瞬で分かることを、数字は時々こんなふうに騙してくる。
