# 番外編: ドットを打つ道具を、ドットのゲームに添える

ステージエディタ、png2chr、目パチエディタ。このプロジェクトには気づけば Web ツールが3つも生えていた。今日、4つ目が生えた。CHR-ROM エディタである。

## CHR を「直接」さわりたい

これまでタイルを直すには、PNG を描いて png2chr に通すか、Python スクリプトで `.byte` を吐き直すかしていた。だが「この 1 ドットだけ直したい」というときに、そのパイプラインは大げさすぎる。ファミコンのグラフィックは結局のところ 16 バイト/タイルの 2bpp プレーンデータなのだから、ブラウザで直接ビットをいじれればいい。

エディタは `docs/tools/chredit/` に単一 HTML で置いた。例によって外部依存ゼロ、インラインの style と script だけ。開くと `docs/editor/base.nes`(ステージエディタと共用の最新 ROM)を fetch して、iNES ヘッダから CHR オフセット(16 + PRG 32KB = 0x8010)を計算し、16KB を丸ごと読み込む。CNROM の 2 バンク × PT0/PT1 で、タイル一覧は 256 枚 × 4 ページ構成になった。

## キーボードはファミコンの操作感で

要件は明快だった。**1・2・3・4 キーで色を選ぶ(色0 = 透明)、矢印カーソルで移動、スペースで色を置く**。マウスでドラッグ描画もできるが、キーボードだけで完結する操作系は、どこか十字キーと A ボタンでドットを打っていた時代の風情がある。透明(色0)は市松模様で描いた。Shift+クリックのスポイト、Cmd/Ctrl+Z の UNDO(タイル単位のスナップショットを 300 段)も付けた。

パレットは `src/ppu.s` の `palette_data` をそのまま持ち込んだ。BG の悪魔城風 4 色、少女狩人、決意マン、パタパタ、石化。ゲームと同じ色で編集できるのは思いのほか気持ちがいい。スウォッチをダブルクリックすると NES 64 色パレットが開いて差し替えられる。

## セーブは3系統、そして動かして確かめる

セーブ・ロードは localStorage(ブラウザに保存)、`.chr` バイナリの書き出し、そして base.nes の CHR を差し替えた `.nes` の書き出しの 3 系統。書き出した ROM は cluade-famicom-emu にドロップすればそのまま遊べる。ステージエディタで確立した「編集 → ROM 書き出し → 即プレイ」の流れを、今度はグラフィックでなぞった形だ。

最後にアニメーションチェック。歩き 16 コマの少女狩人を作ったとき、一番欲しかったのはこれだった。「＋現在のタイル」でコマを積んで、fps スライダで速度を変えながら再生する。16x16 モードにすると右・下・右下のタイルを合成してくれるので、2x2 タイルのスプライトの歩きもそのまま確認できる。

ドットのゲームに、ドットを打つ道具が揃っていく。道具が揃うと、また直したいところが見えてくる。困ったものである。
