# クソ面白くしといて

最短で最重量の注文が来た。「ゲーム自体があんまおもろくない。クソ面白くしといて」。正しい。歩くレモンを矢で撃って右へ歩くだけのゲームだった。面白さの分解を試みた——脅威の多様性、手応え、報酬のループ、そして「常に何かが起きている」こと。

## 敵は3種類になった

歩くだけだった決意マンに、仲間が2種類増えた。**コウモリ**はサイン波で上下しながら倍速で飛ぶ。地上を歩いていると頭上から降ってくるし、倒すにはジャンプ撃ちか空中踏みが要る。**ホッパー**は放物線でプレイヤーめがけて跳ぶ。跳び際に必ずこちらを向くので、着地点を読んで矢を置く駆け引きになる。敵ごとに現在Y座標を持たせ、当たり判定を全て「敵の実座標」ベースに書き直した。矢の判定に+8のバイアスを入れて、狙いが1ドットずれても当たる寛容さも仕込んだ。

## 倒しても終わらない

一番効いたのはリスポーンだと思う。倒した敵は約4秒後、画面右端の先から再登場する。ステージは「掃除したら安全」な場所ではなくなり、常に圧がかかる。その圧の見返りが**空中踏みコンボ**——着地せずに踏み続けると200→400→800→1600→3200点と倍々。コウモリを足場に跳び継ぐ変態プレイに報酬が出る。

## 手応えの科学

撃破の瞬間、世界が3フレーム止まり (ヒットストップ)、背景が一瞬白く光る (キルフラッシュ)。数字にすると馬鹿らしいほど小さいが、あるのとないのとでは「殴った感」がまるで違う。コインは30枚ごとに1UP——コインに初めて意味ができた。ボスはHPが減ると跳ぶ間隔が44Fから16Fまで縮み、低HPでは跳びが強く追尾が倍速になる。終盤は別の生き物になる。

面白さは足し算ではなく掛け算だった。脅威(コウモリ)×報酬(コンボ)×圧(リスポーン)×手応え(ヒットストップ)。テストは115本、全部緑。ROMは35本目。

## 追記: 石化と、足場としての敵

続けて設計の核が届いた。「床の穴を多めに、敵を踏みながら進むゲーム性へ」「上/下+攻撃で矢を縦に」「パズル要素を」「パタパタのように上下する敵を」——そして決定打、「**敵は矢を当てると硬化する。硬化した状態なら上に乗れる**」。

これで武器の意味が反転した。矢はもう敵を殺さない。**石に変えて足場を作る**。殺すのは踏みつけだけ。広い穴(7〜9列 = ジャンプでは届かない)の中空にパタパタが浮いていて、タイミングよく矢で石化させ、その上に乗り、目覚める前に次へ跳ぶ。目覚めの5秒前からは石が点滅して警告する。下+Bの真下撃ちは眼下の敵を飛行中に石化させる橋作り、上+Bはコウモリ迎撃。パワー矢は貫通をやめて「2本目の矢」になった——足場を2つ同時に作れる。

実装面では、硬化 (flag=4) は灰色パレットに切り替わり、プレイヤーの着地判定がタイルと同じ式 (面の上端-32) で敵の上端を受け付ける。目覚めた瞬間に頭上のプレイヤーごと動き出すスリルはバグではなく仕様である。ゴールには旗が立った。ポールに触れて STAGE CLEAR!——スーパーマリオへの最後の敬礼。テストは131本 (硬化・縦矢・パタパタの harden_test を新設)、全部緑。ROMは36本目になった。

## 追記2: 調整の嵐

仕様が磨かれていく。石化は1.5秒スタートで、追い撃ちごとに 3秒→4.5秒→6秒 と延び、5発目で砕けてランダムアイテム (星かパワー矢) を落とす。石化した敵は横からは壁 (上に乗れて下はくぐれる一方通行)。アニメも止まる——羽ばたいたまま固まったコウモリは、ちゃんと「石」に見える。

主人公は頭身が下がって頭上に8pxの空白があったので、当たり判定の実体を y+8 からに見直した。天井は8px高くまでくぐれ、敵の接触帯も8px狭く、理不尽が減った。やられたときは横にごろんと倒れる——硬直ポーズを90°回転した8タイルを焼いて、32x16で寝かせた。ゴールの旗はキャッチするとスルーッと滑り降り、高さに応じて10点ずつ入る (スコアに十の位が生えた)。タイトルはフェードイン完了まで入力を受けず、STARTのウィンクはユーザー定義の目パチ (半目→閉じ) で目を閉じる。

そして今日いちばんの収穫はバグだった。`add_score` が X レジスタを壊していて、敵ループの中で呼ぶと別のスロットに書き込む。石化破壊が動かない原因を追ってトレースを眺めたら、dir に 45 が入っていた——ハードニング時間テーブルの値が隣の変数に漏れていたのだ。add_score 側で X を保存するよう直した。サブルーチンの契約は、コメントに書くだけでなく守らせること。テストは137本、全部緑。ROMは37本目。

## 追記3: 顔と、セリフと、決意

ラウンド画面が生まれ変わった。黒画面に「STAGE 1-1」だけだったのが、タイトル画像から切り出した主人公の顔 (32x24、ゲームバンクPT1の空き $D0- に12タイル) が表示され、しかも目パチする (閉じ目差分6タイルをNMIがネームテーブルに書き換える)。その下にはステージごとのセリフ——「けついマンを たおさざるを えない！」。ひらがな31文字を8x8で手打ちした自作かなフォントである。「い」が「リ」に見える事故を1回起こした。

ゲームルールも締まった。敵は踏んでも倒せない (バウンドのみ)。倒す手段は矢5発の石化破壊だけ。武器と移動の役割分担が完全に分離した。タイトルのウィンクは「両目閉じ」ではなく本物の片目ウィンク (手前だけ閉じ、奥は白目のまま) に。そして CONTINUE が本当に機能するようになった——ゲームオーバーのリセットを跨いで最終到達ステージをマジックバイト付きで保持し、そのステージの頭から再開する。コンティニュー画面のあるファミコンゲームは、もう「ちゃんとしたゲーム」である。

## 追記4: 美咲フォントと、16の倍数の魔法

「セリフは顔の横に。フォントが読みにくいのでerisaフォントを」。恵梨沙フォントは調べると利用許諾が必要で、公開リポジトリには積めない。代わりに、同じ8x8文化圏の定番でライセンスが自由な**美咲フォント**を採用した (実はこのゲームの英数字フォントの先祖でもある)。手打ちの自作かなは31文字ぶんの努力もろとも退役——プロのフォントは1文字目から違った。

「顔はタイトル画面と同じものを」も効いた。前回はクロップを3色に量子化していたが、切り出し位置を16の倍数 (176,48) に揃えたら、タイトルの属性ブロックとぴったり重なり、なんと顔全域が同一パレットだと判明。量子化が消えてピクセル単位でタイトルと同一になった。NESの制約は、整列した者にだけ優しい。顔は左、セリフは右横、目パチ付き。ROMは39本目。

## 追記5: せきかのやで

1-1のセリフが公式に決まった。「せきかのやで けついマンの けついを かためてみせる！」——石化の矢がゲームの顔になった宣言だ。長文になったので改行センチネル付きの2行表示に。ここで「ン」が消える事件が起きた。かなグリフの通し番号がちょうど $FF に達し、空白センチネルと衝突していたのだ。制御コードは $00-$02 の低番地に引っ越させた。

英数字も美咲フォントに統一。自作5x7は役目を終えた。全角変換で「-」だけがeuc_jpに存在せず(FULLWIDTH HYPHEN-MINUSの罠)、MINUS SIGNへの差し替えで解決。ついでに下撃ちを空中限定にして、地上で矢を地面に吸われる無駄をなくした。ROMは40本目。区切りがいい。

## 追記6: 音の手触り

SEを総取り替えした。ジャンプ音は本家スーパーマリオの smb.asm からレジスタ列 ($82/$A7 → $5F/$F6 → $48/$BC) を移植——ハードウェアスイープが3相で切り替わる、あの「トゥイン」だ。ショットは矩形波のザップをやめてノイズの短いヒスに (弓の風切り音)。敵ヒット音は5段階: 硬化するたびノイズ周期が上がって重くなり、5発目は短周期モードを混ぜた金属的な破壊音で砕ける。耳で「あと何発か」が分かる。アイテム取得は駆け上がりアルペジオ、STARTは矩形波2本の高速アルペジオ+三角波ルートの和音ファンファーレになった。

そして今日もまた同じ穴に落ちた。sfxn_type を ZP の途中に挿入して、以降の変数が全部1バイトずれ、テストのポーク先が狂って大量の偽退行が出た。ZPは末尾追加が鉄則——コメントにそう書き足しておいた。二度あることは、コメントにしておけば三度目は防げる。はず。ROMは41本目。
