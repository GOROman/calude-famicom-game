# 番外編: 設定画の彼女が、16ドットに宿る

新しいスプライトシートが届いた。走り4コマ、ジャンプ3コマ、弓4コマ。チビキャラ調にリファインされた少女狩人が、黒背景の上で生き生きと動いている。これをベースに主人公を打ち直してほしい、と。

## 13分の1への旅

シートの1ポーズは約200x240ピクセル。ゲーム内の彼女は16x24。つまり13分の1に煮詰めなければならない。手作業では日が暮れるので、変換パイプラインを書いた (`tools/sheet2nes.py`)。

工程は4つ。まず有彩色画素の連結からポーズを自動検出(白いラベル文字や矢アイコンは弾く)。次に色分類——SP0 パレットは透明・茶 ($17)・ピンク ($25)・肌 ($36) の実質3色なので、青いスカーフは茶へ、白いソックスは肌へ、色相ルールで潰す。そして等比縮小+多数決量子化。最後に孤立ピクセルを均すデスペックル。

最初の出力は茶色の塊だった。輪郭線の暗色が多数決で勝ちすぎたのだ。色分類を最近傍距離から色相ルールに変え、中身の色をやや優遇したら、ピンクのワンピースと肌が浮かび上がった。仕上げに顔の肌ブロブを探して目を1ドット置く後処理。たった1ドットだが、これがあるとないとでは別人である。

## 顔アイコン事件

差し替え後、HUD の残機表示が無になった。旧スプライトでは立ちポーズの頭タイルをそのまま顔アイコンに流用していたが、新しい彼女は頭の位置が違い、そのタイルはほぼ髪の毛だけになっていたのだ。8x8 タイル1枚に顔が収まっていないなら、収めたものを作ればいい——立ちポーズの顔まわり 8x8 を切り出した専用アイコンタイルを、未使用だったかな「・」の跡地 ($5F) に新調した。

検証はいつものヘッドレス実行。タイトルから START、歩いて、跳んで、弓を放って、各ポーズをフレームバッファから切り出して確認した。前回のグリッド配置のおかげで、CHR エディタのキャラアニメプレイヤーでも新しい走りがそのまま再生できる。設定画の彼女が、16ドットの中で今日も走っている。

## 追記: エディタからの里帰り

打ち直したドットを、今度は CHR-ROM エディタで手直しした calude.chr が届いた。差分を取ると 21 タイル——歩きの頭、ジャンプの体、弓の腕。機械の量子化では出せない人の手の跡だ。書き出された 16KB を sprites.s に書き戻し、リビルドした ROM の CHR がバイト単位で一致することを確認。エディタで打ったドットが、そのままソースコードになってカセットに還る。ツールチェーンが一周つながった瞬間である。
