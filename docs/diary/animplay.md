# 番外編: 市松模様は「透明」と読む

grok が生成した少女狩人の動画が届いた。368x800、6秒、145コマ。背景は市松模様——つまり「ここは透明のつもり」という記号である。記号は記号のままでは使えない。本当に透明にしなければ。

## 中央値の罠とフラッドフィル

最初は時系列の中央値で背景プレートを作って差分キーを試みた。結果は穴だらけの狩人だった。彼女はその場で足踏みしているので、時間方向の中央値を取っても彼女自身が写り込む。市松の色 (白 248 / 灰 224) で直接キーしようにも、ブーツのファーや白い衣装がまったく同じ色である。

決め手は連結性だった。市松候補 (明るい無彩色) のうち、**画面の外周に4連結でつながっている成分だけ**を背景と確定する。ファーや白い襟は輪郭線に囲まれて外周から切れているので生き残る。圧縮でにじんだ縁のハローは「背景を1pxずつ膨らませるが、暗い輪郭線には踏み込まない」条件付き膨張で始末した。パイプラインは `tools/video2frames.py` に収めてある。

## URL がまた保存データになる

再生ツールは `docs/tools/animplay/`。145コマのサムネイルをクリックで ON/OFF (Shift で範囲選択)、fps スライダでループ再生。背景は透過確認の市松・グリーンバック・黒から選べる。市松を消す道具のプレビュー背景が市松なのは、われながら味わい深い。選んだコマと fps はビットマスクにして URL ハッシュへ——ステージエディタから続く「URL が保存データ」の家訓は、ここでも守られている。

## 追記: 引き算の指示

「透過PNG処理が汚いのでやらなくてOK。先頭32コマだけでOK」。フラッドフィルだ条件付き膨張だと工夫を重ねたキーイングは、白い衣装ににじんだ市松までは消せなかった。道具は正直に、素材は素のままに——フレームは無加工の先頭32コマ (2MB) に差し替えた。作った仕組みは tools/video2frames.py に残っている。使う日が来たら磨けばいい。

## 追記2: 動画からファミコンへ、直通便

プレイヤーに「ファミコンスプライト変換」を追加した。選択したコマをブラウザ内で 16x32・3色+透明の NES スプライトに変換し、本編の隣で同じ fps でループ再生する。変換は sheet2nes.py と同じ手筋——市松をフラッドフィルで除いて前景を取り、色相ルールで茶/ピンク/肌に潰し、多数決で 16x24 に煮詰める——を JavaScript に移植したものだ。

書き出しは CHR エディタ互換のグリッド配置 (縦の隣=+16)。.chr を CHR エディタに読み込めば、そのままキャラアニメプレイヤーで再生できる。grok の動画が、ワンクリックの列車を乗り継いで、ファミコンのパターンテーブルまで届くようになった。
