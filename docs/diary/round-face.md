# 番外編: ラウンド画面に、あの顔を

ラウンド画面の顔は 4x3 タイルの小さな似顔絵だった。タイトル画面にはあんなに大きく美しい一枚絵があるのに、である。「下にはバンク切り替えして顔を出す(顔はタイトルと同じもの)」——今回の指令はシンプルで、そして CNROM の面白いところに踏み込む話だった。

## 1フレームに2つのバンク

CNROM のバンク切替は CHR 8KB を丸ごと差し替える。上半分でフォント(ゲームバンク)、下半分でタイトルの顔(タイトルバンク)を出すには、走査線の途中でバンクを切り替えるしかない。タイトル画面で実績のあるスプライト0ヒットをラウンド画面にも仕込んだ。

上半分は STAGE 1-1、セリフ、残機。行13に「────」の区切り線を引き、その裏に同じ '-' タイルのスプライト0を隠す。ヒットした瞬間はまだ区切り線の走査中なので、約9ライン分だけサイクルを潰してから、タイル $00 だけの空白帯 (行14-15) でバンクとパターンテーブルを同時に切り替える。タイル $00 はゲームバンクでは透明、タイトルバンクでは黒——どちらでも真っ黒なので、切替タイミングが多少ブレても継ぎ目は絶対に見えない。

## ネームテーブルは再利用できる

下半分の絵は、タイトルのネームテーブル (RODATA に置いてある 1024 バイト) から行4〜16・列20〜31 を切り出してコピーするだけ。属性テーブルも同じ窓をコピーする。属性は 4x4 タイル単位なので、コピー元とコピー先の行位置を 4 の倍数で揃えるのがコツだ (タイトル行4 → 画面行16)。パレットはタイトル画像パレットを丸ごと使い、テキストはそのパレット0の色1 ($37 = 骨色) がそのまま使えた。偶然ではなく、どちらも同じ世界の色だからである。

目パチはタイトルの目スプライトのテーブルを Y+96 して流用した。タイトルで彼女がまばたきしていたのと同じ目が、ラウンド画面でもまばたきする。「顔はタイトルと同じもの」という指令は、データの意味でも完全に同じもの、という形で実現したことになる。
